# Versal (Vercel) Deployment Configurations

This folder contains all Versal / Vercel related deployment configuration files for the Institute Management & Assessment Portal.

### Files inside this folder:
* **`vercel.json`**: Root project Vercel configuration for automated builds, output directory (`frontend/dist`), and `/api` reverse-proxy routing.
* **`frontend-vercel.json`**: Frontend folder Vercel configuration for deployments where the root directory is set to `frontend/`.
